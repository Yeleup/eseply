# Модуль: Адресные справочники

## Терминология

Город в коде называется `City`.

Регион в коде называется `Region`.

Улица в коде называется `Street`.

Таблица городов называется `cities`.

Таблица регионов называется `regions`.

Таблица улиц называется `streets`.

## Назначение

Модуль хранит справочники городов, регионов и улиц внутри tenant-организации.

Города используются как верхний уровень адресного справочника.

Регионы принадлежат городу.

Улицы принадлежат конкретному региону.

## Основные поля города

| Поле | Описание |
|---|---|
| Организация | Tenant-организация, поле `organization_id` |
| Название | Название города, поле `name` |

## Основные поля региона

| Поле | Описание |
|---|---|
| Организация | Tenant-организация, поле `organization_id` |
| Город | Город, поле `city_id` |
| Название | Название региона, поле `name` |

## Основные поля улицы

| Поле | Описание |
|---|---|
| Организация | Tenant-организация, поле `organization_id` |
| Регион | Регион, поле `region_id` |
| Название | Название улицы, поле `name` |

## Правила

Город относится к tenant-организации.

Название города должно быть уникальным внутри tenant-организации.

Регион относится к городу.

`organization_id` региона должен совпадать с `organization_id` города.

Название региона должно быть уникальным внутри одного города (заменяет уникальность внутри организации).

Улица относится к tenant-организации и региону.

`organization_id` улицы должен совпадать с `organization_id` региона.

Название улицы должно быть уникальным внутри одного региона tenant-организации.

При удалении организации удаляются её города, регионы и улицы.

При удалении города удаляются его регионы и улицы.

При удалении региона удаляются его улицы.

В карточке абонента город выбирается из справочника текущей tenant-организации.

После выбора города список регионов должен показывать только регионы выбранного города.

После выбора региона список улиц должен показывать только улицы выбранного региона.

Город абонента отдельно не хранится и определяется через регион.

Нельзя сохранить абонента с регионом из другого города.

Нельзя сохранить абонента с улицей из другого региона или другой tenant-организации.

Регион или отдельная улица могут использоваться как зона ответственности контроллера внутри организации.

Назначение зоны ответственности контроллера действует только внутри конкретной привязки пользователя к организации.

Назначения регионов и улиц не используются для ролей, отличных от контроллера.

## Административная панель

Города управляются в профиле организации как связанный справочник.

Регионы управляются внутри карточки города как связанный справочник.

Улицы управляются внутри карточки региона как связанный справочник.

Отдельные разделы городов и регионов в навигации не используются.

В standalone-карточке региона можно выбрать город региона.
